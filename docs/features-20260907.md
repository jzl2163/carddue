# 新功能使用说明

## 1. 创建账户

打开登录页，点击“创建新账户”，填写邮箱、至少 12 个字符的密码、确认密码和账户默认时区，然后提交。部署者需将 `ALLOW_REGISTRATION` 设为 `true` 才会显示注册入口；首次初始化仍使用部署时提供的 `SETUP_TOKEN` 创建管理员账户。

## 2. 归档与永久删除

在卡片详情的“卡片设置”中，点击“归档”可暂停这张卡的日常管理并保留历史。原有 `DELETE /cards/{id}` 继续表示归档。需要彻底移除卡片时，在同一处点击“删除信用卡”并确认；`DELETE /cards/{id}/permanent` 会永久删除该卡、账期、事项、提醒任务和投递记录，不能恢复。

## 3. 发行地区与卡片时区

添加或编辑卡片时，发行地区可以留空。卡片时区留空时跟随账户时区；填写时使用 IANA 时区名称，例如 `America/New_York`。系统会按卡片时区计算日期，并自动处理夏令时；发行地区不会自动修改时区。

## 4. 发卡行与卡组织

“发卡行”和“卡组织”输入框支持搜索常见选项，也允许直接输入自定义名称。发卡行使用通用银行图标，并沿用卡片的识别色；卡组织会对 Visa、Mastercard、银联等常见名称显示对应标识。

## 5. 账单金额显示

账期金额未填写时不显示金额，填写 `0.00` 时仍会显示 `0.00`。编辑账期时留空金额即可清除已保存的金额。

## 6. 免息期排行榜

进入“免息排行”后，可在“今天消费”和“未来一年理论最长”之间切换。排行榜按每张卡的当地日期计算：账单日当天的消费计入当期，天数是还款日期减消费日期，不把消费当天另加一天；“未来一年理论最长”按上一账单日次日消费估算。实际入账时间、免息资格和银行宽限规则以发卡行规定为准。

这些功能不要求申请域名、连接银行或提供第三方服务凭据；登录账户即可使用。请勿在卡片信息或备注中保存完整卡号、CVV、PIN 或银行密码。

## 总览中的免息排行

总览在“即将到来”之后显示今天消费预计免息期最长的前三张卡，包含预计还款日、天数和跨时区提示。点击卡片进入详情，点击“查看完整排行”进入完整排行榜。模块独立加载，读取失败时可单独重试。
