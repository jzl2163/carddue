# 使用指南

首次打开登录页面，使用私密配置中的 SETUP_TOKEN 创建管理员。保存账户密码并设置时区。初始化完成后使用正常登录。

在“信用卡”添加昵称、账单日、还款规则和可选尾四位。固定还款日需要选择同月或次月；账单后若干天模式按该期账单日期推算。录入后对照实际银行账单核对。
进入卡片详情查看账期，必要时覆盖单期日期或金额。实际完成还款后再标记已还款；标记仅为管理记录。撤销后检查提醒状态。归档用于停止日常管理，保留历史。

“日历订阅”建立私密订阅，选择卡片、事件类型与隐私等级。复制 URL，在设备日历里选择通过 URL 订阅；下载后导入不会持续更新。
订阅链接包含访问凭据，应像密码一样保管。泄露时撤销/轮换并在设备上重新订阅。刷新频率由客户端决定。

“通知中心”先配置渠道和模板，再配置日期类型、提前天数和发送时刻。测试发送会真实投递到所配置目的端；请自行选择专用测试渠道。通过投递历史核对结果。
设置中检查时区、会话和系统状态。浏览器网络中断时先刷新核对操作是否已经完成，避免重复提交。
